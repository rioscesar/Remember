# Product principles

## Evidence before imagination

Remember reconstructs what can be supported by captured evidence. It must not present a panorama, depth effect, stock environment, or generated material as spatial reconstruction.

## Absence has meaning

Missing information is not a defect to conceal. When evidence ends, the memory fades.

## Original media is sacred

Never modify or overwrite the user's source media. Remember stores references and derived reconstruction data, not replacements for the originals.

## Private by default

A person's memories are exceptionally sensitive data. Prefer local computation and storage.

## Reconstruction and generation are different

Future generative completion must always be explicitly distinguishable from evidence-backed reconstruction.
